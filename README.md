# DevNotes — Записки разработчика

Простая настольная программа для Windows: ведите заметки по **логике своих проектов** в одном месте.

## Возможности

- Окно из двух частей: слева — список проектов, справа — записи по выбранному.
- Закреплённый раздел **«Общая логика»** — то, что общее для всех программ сразу.
- По каждому проекту 4 вкладки: **Описание**, **Логика работы**, **Ссылки и заметки**, **Задачи** (чек-лист с галочками).
- **Поиск** по всем записям (названия + текст внутри).
- Кнопки: новый / переименовать / удалить проект.
- **Тёмная тема** в стиле VS Code.
- Автосохранение. Все данные хранятся локально в `%APPDATA%\MAMONOV\project_notes.json`. В интернет ничего не отправляется.

## Запуск

Нужен Python 3 (на Windows tkinter идёт в комплекте):

```bash
python project_notes.py
```

## Сборка .exe

```bash
pip install pyinstaller
pyinstaller --noconsole --onefile --name DevNotes project_notes.py
```

Готовый `DevNotes.exe` появится в папке `dist`.
