# Настройка Google Drive (простой способ)

## Что нужно

Google Drive for Desktop должен быть установлен.

## Настройка

1. Открой файл `google_drive_sync.py`
2. Найди строку:
   ```python
   GOOGLE_DRIVE_PATH = r"G:\Мой диск\MAMONOV\DevNotes"
   ```
3. Если путь к Google Drive другой — измени его
4. Готово!

## Как работает

- Файлы копируются в папку `G:\Мой диск\MAMONOV\DevNotes\`
- Google Drive автоматически синхронизирует их с облаком
- При каждом сохранении создаётся резервная копия с датой
- При запуске программы — попытка загрузить последние данные с Drive

## Резервные копии

На Google Drive сохраняются все версии:
```
project_notes.json           — текущая версия
project_notes_20261004_192500.json  — копия от 04.10.2026 19:25
project_notes_20261004_193000.json  — копия от 04.10.2026 19:30
...
```

Можно восстановить любую версию из папки на Google Drive.
